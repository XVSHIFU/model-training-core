# 历史兼容模块，不是主训练入口

此目录仅保留现有单元测试及历史数据构建审计需要的三个模块：

- `build_datasets.py`：历史去重、指纹、切分及清单逻辑。
- `build_train_v4.py`：历史数据来源优先级及训练集合并逻辑。
- `label_gold.py`：历史标注手册与抽样逻辑。

这些模块的默认数据、旧目录布局和模型未随公开仓库分发。保留代码不表示旧默认命令可直接运行；部分历史命令还会写入标签或构建文件，应在明确准备好的独立本地环境中用于历史复现。

新任务的统一主流程使用 `model-workflow`，参考仓库主 README 和 `examples/README.md`。新框架负责记录数据用途、检查隔离、保护原资产并为每次运行创建独立目录。

旧 promotion、freeze、打包及默认验收脚本已从本仓库移除。不要为新框架恢复或依赖那条自动晋级路线；现有正式模型的读取兼容由上传适配器保留，工程验证不会自动替换正式模型。
